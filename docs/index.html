👋 软件简介 👋 Overview

weibo_one_spider 是一款面向微博数据采集场景的桌面 GUI 工具。 支持关键词搜索采集、主页微博采集、评论采集、用户信息采集等多种模式， 采集结果自动导出为 CSV 文件。内置 Cookie 小工具，无需手动配置复杂参数， 下载客户端后登录即可使用。

weibo_one_spider is a desktop GUI tool for Weibo data collection. Supports keyword search, profile post crawling, comment scraping, and user info extraction with automatic CSV export. Built-in cookie tool eliminates manual configuration — just download, log in, and start collecting.

🟢 是否需要安装 Python？

🟢 Do I need to install Python?
No. The software is packaged as a standalone desktop app — just download and run.

软件内置 Cookie 小工具，只需在工具中扫码或登录微博账号即可一键获取 Cookie，全程无需手动抓包，简单快捷。
🟢 How do I get the Weibo Cookie? Is it complicated?
The built-in Cookie Tool lets you obtain your Weibo session with a simple login — no manual packet capture required. It takes seconds.

不会。软件在采集过程中持续保存结果，网络异常或任务中断不会丢失已采集的数据。
🟢 Will I lose data if crawling is interrupted?
No. Results are saved continuously — network issues or interruptions won't wipe collected data.
🟢 支持导出哪些格式？
支持导出 CSV 格式，Excel / WPS / Numbers 可直接打开，也可导入 Python / R 等工具进行进一步分析。
🟢 What export formats are supported?
CSV format — opens directly in Excel / WPS / Numbers, and can be imported into Python / R for further analysis.
