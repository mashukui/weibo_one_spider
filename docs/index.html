核心功能

功能按常见微博数据整理流程组织：先按关键词或主页采集帖子，再按链接采集评论和用户公开信息。

关键词

关键词微博采集

按关键词搜索微博帖子，整理正文、作者、发布时间、转发、评论和点赞等信息。

主页

主页微博采集

输入博主主页链接，采集其公开微博列表、话题标签和互动数据。

评论

帖子评论采集

根据微博帖子链接采集评论内容、评论者资料、点赞数、IP 属地和评论级别。

用户

用户信息采集

采集用户主页、认证、粉丝、关注、微博数、信用和标签等公开资料字段。

常见问题

这里回答购买前最常见的问题。更细的字段说明、Cookie 说明和反馈格式请查看 GitHub README。

是否需要安装 Python？

不需要。软件已经打包为桌面客户端，下载对应系统版本后即可运行。

Cookie 是做什么用的？

Cookie 用于让软件以当前账号状态访问平台公开数据。请使用自己的微博账号 Cookie。

为什么有些微博采不到？

可能是微博权限、链接格式、登录态、网络环境或平台限制导致。建议优先使用浏览器地址栏中的完整链接。

采集中断后数据会丢失吗？

软件会在采集过程中持续保存结果，已完成部分通常会保留在 CSV 文件中。

准备整理微博公开数据？

先看演示或下载最新版，也可以直接进入商品页开通授权。
